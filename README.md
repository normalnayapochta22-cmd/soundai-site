| `--border-hover` | `rgba(200, 169, 110, 0.5)` | Границы при наведении |

### Типографика

**Шрифты (Google Fonts):**
- **Заголовки:** `Cormorant Garamond` (serif, вес 300-600)
- **Основной текст:** `DM Sans` (sans-serif, вес 300-600)

**Размеры:**
- H1 (Hero): `clamp(3.5rem, 8vw, 6rem)` — вес 300
- H2 (Секции): `clamp(2.5rem, 5vw, 3.5rem)` — вес 300
- H3 (Карточки): `20-24px` — вес 400
- Body: `14-17px` — вес 300-400
- Мелкий текст: `11-13px` — uppercase, letter-spacing 0.1-0.2em

### Визуальный стиль
- **Эстетика:** Тёмная, премиальная, минималистичная (luxury audio brand)
- **Формы:** Квадратные (без скруглений) — более строгий премиум-вид
- **Анимации:** Плавные, cubic-bezier(0.4, 0, 0.2, 1)
- **Эффекты:** Золотое свечение, shimmer на тексте, noise-текстура фона

## Эффекты и анимации

### Desktop
1. **Кастомный курсор** — золотой круг, следует за мышью
2. **Glow-эффект** — большое свечение за курсором
3. **Hover на карточках** — подъём + золотая рамка + свечение внутри
4. **Shimmer на заголовке** — переливающийся градиент на золотом тексте
5. **Аудио-визуализатор** — 12 баров с волновой анимацией
6. **Плавающие градиенты** — медленное движение фоновых пятен
7. **Вертикальные линии** — пульсирующие линии на фоне hero
8. **Scroll reveal** — секции появляются при скролле
9. **Noise texture** — тонкая текстура шума на всём фоне

### Mobile
1. **Ripple effect** — волна при тапе на кнопки
2. **Scale on tap** — уменьшение при нажатии на карточки
3. **Parallax** — градиенты двигаются при скролле
4. **Pulsing CTA** — пульсация основной кнопки
5. **Counter animation** — числа статистики анимированно появляются
6. **Text glow** — свечение на заголовках и ценах
7. **Always-on waves** — волны в треках анимируются всегда

## Как редактировать

### Текст
Весь контент находится в `index.html`. Ищите нужный текст и заменяйте.

### Цвета
Все цвета определены в начале CSS в блоке `:root { ... }`. Меняйте переменные.

### Тарифы
Ищите секцию `<!-- PRICING -->` и редактируйте карточки `.pricing-card`.

### Контакты
Ищите `soundvision` в файле и заменяйте на реальные данные.
